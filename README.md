# loti.nordl.dev

The Loti Studios website: one static page (`index.html`) and its pictures (`assets/`). Hosted on GitHub Pages; the
subdomain is a CNAME record at GoDaddy (`loti` -> `lordoftheidiot5.github.io`), and the `CNAME` file here tells Pages
which name it answers to.

The pictures and the clip come from the Wickerwood repo (`D:\ForkedTongue\marketing`): `make_x_images.py` (logo, share
image) and `clip/make_clip.py` (the clip, its poster and the stills).
